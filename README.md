# VPNHots — VPN Hotspot UI Build

Repository dành cho việc biên dịch bản thử nghiệm **VPN Hotspot UI Refresh** từ mã nguồn [Mygod/VPNHotspot](https://github.com/Mygod/VPNHotspot).

- Nhánh mặc định là mốc khởi tạo; mã nguồn bản vá và GitHub Actions nằm trên nhánh `build/vpnhotspot-ui`.
- Giao diện Mint Green/Modern Dark là bản thử nghiệm chưa kiểm chứng trên thiết bị.
- Chức năng điều khiển V2RayTun và chọn server chưa được tích hợp.
- Mã nguồn gốc theo giấy phép [Apache License 2.0](https://github.com/Mygod/VPNHotspot/blob/master/LICENSE).

Không tải APK chưa được biên dịch thành công hoặc không rõ chữ ký lên điện thoại chính.
